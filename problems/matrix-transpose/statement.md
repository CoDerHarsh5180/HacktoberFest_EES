You are given a matrix of size `r × c`. Print its transpose, which is a matrix of size `c × r` where the rows and columns are swapped.

### Input

The first line contains two integers `r` and `c` (1 ≤ r, c ≤ 100).
The next `r` lines each contain `c` space-separated integers.

### Output

Print `c` lines, each containing `r` space-separated integers, representing the transposed matrix.

### Example

**Input**
```
2 3
1 2 3
4 5 6
```

**Output**
```
1 4
2 5
3 6
```
